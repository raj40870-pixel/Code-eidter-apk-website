When you launch Code Editor, tap the Three Lines (≡) icon on the top-left toolbar (pointed by the red arrow) to slide open the EXPLORER drawer on the left.

    Click 1: Tap the Three Lines (≡) button in the top action bar.
  • ✓
    Explorer Slides Open: Displays your project structure (CppStarter), default source files (main.cpp, index.html), and explorer management controls.

STEP 4 • COMPILERS & LIBRARIES

Install Language Toolchains & Packages

You can install any language compiler (Rust, Python, Clang C++, Java, Node.js) through the built-in guide or directly via the terminal.

  • ✓
    Method A (In-App Guide): Tap Three-Dots (⋮) > 🛠️ Compiler Setup Guide. Select any language and tap Install (pointed by red arrow).
  • ✓
    Method B (Terminal Command): Open terminal and type pkg install clang, pkg install python, or pkg install rust.
  • ✓
    Fast CDN: Pre-compiled ARM64 native binaries download in seconds and unpack directly into your app environment!
$pkg install clang python rust nodejs
